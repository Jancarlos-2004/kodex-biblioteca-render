## 2. Matriz de Requisitos No Funcionales (NFR)

| ID | Categoría | Requisito Verificable | Verificación y Evidencia en KODEX | Estado |
|---|---|---|---|---|
| **NFR-01** | Usabilidad | Formularios identifican campos obligatorios con asterisco (*) y validan errores con mensajes descriptivos. | Jakarta Validation (`@NotBlank`, `@Min`, `@Email`) con Bootstrap `.is-invalid` y `.invalid-feedback`. | **CUMPLIDO** |
| **NFR-02** | Seguridad | Contraseñas protegidas mediante hash BCrypt y rutas web protegidas por roles con Spring Security. | `BCryptPasswordEncoder` en `SecurityConfig`, rutas mapeadas con `hasRole(...)` y `hasAnyRole(...)`. | **CUMPLIDO** |
| **NFR-03** | Integridad | Préstamos respetan el estado de los ejemplares y claves foráneas en base de datos relacional. | Constraints de integridad referencial FK en base de datos MySQL y validaciones en Java. | **CUMPLIDO** |
| **NFR-04** | Rendimiento | Consultas y filtros responden de manera inmediata en entorno local (< 200 ms). | Consultas indexadas mediante Spring Data JPA con lazy loading y proyecciones optimizadas. | **CUMPLIDO** |
| **NFR-05** | Mantenibilidad | Código organizado por paquetes MVC estrictos sin capa Service según restricción académica. | Paquetes limpios: `com.kodex.model`, `com.kodex.repository`, `com.kodex.controller`, `com.kodex.config`. | **CUMPLIDO** |
| **NFR-06** | Compatibilidad | Interfaz web responsiva para navegadores de escritorio modernos (Chrome, Edge, Firefox, Safari). | Bootstrap 5.3 + HTML5 + CSS3 adaptable con vista móvil y de escritorio. | **CUMPLIDO** |
| **NFR-07** | Trazabilidad | Cada requisito cuenta con criterios Given/When/Then y pruebas documentadas. | Registro de Pruebas BDD completo y pruebas unitarias automáticas en `PrestamoBusinessRulesTest`. | **CUMPLIDO** |
